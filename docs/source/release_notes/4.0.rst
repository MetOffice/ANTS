*********************
ANTS 4.0 (? 2026)
*********************

For a full list of changes see the :milestone:`4.0 release milestone <2>`.

Features
========
- A new horizontal regridding scheme, ``IrisESMFAreaWeighted``, has been
  added. This wraps Iris' ESMF-backed area-weighted regridder
  (``esmf_regrid.schemes.ESMFAreaWeighted`` from the ``iris-esmf-regrid``
  package) for use as an alternative to ``TwoStage``. This scheme is
  experimental, for evaluation purposes only, and may change or be removed
  without notice at a future release.

Deprecations

  ``ants.analysis.flood_fill``; ``ants.analysis.floodfill`` has been deprecated.
